# Практическая задача

Нужно дописать маленький backend на нативном PHP без фреймворка.

Часть проекта уже подготовлена:

- запуск через встроенный PHP-сервер;
- простая маршрутизация;
- JSON-ответы;
- чтение JSON из тела запроса;
- подключение к SQLite через PDO;
- автоматическое создание таблицы `notes`.

Осталось реализовать три эндпоинта:

```text
POST /api/notes
GET  /api/notes
GET  /api/notes/{id}
```

## Порядок выполнения

1. Открыть `src/NoteRepository.php`.
2. Реализовать метод `create()`.
3. Открыть `src/NoteController.php`.
4. В методе `store()` заменить `Response::todo(...)` на вызов репозитория.
5. Проверить `POST /api/notes` через `curl` или Postman.
6. Реализовать `NoteRepository::all()`.
7. В `NoteController::index()` вернуть список заметок.
8. Реализовать `NoteRepository::find()`.
9. В `NoteController::show()` вернуть одну заметку или ошибку `404`.

## Критерии готовности

- `GET /api/ping` возвращает `{ "status": "ok" }`.
- `POST /api/notes` создаёт заметку и возвращает статус `201`.
- `GET /api/notes` возвращает список заметок.
- `GET /api/notes/1` возвращает одну заметку.
- Если заметка не найдена, API возвращает `404`.
- Если `title` или `text` пустые, API возвращает `422`.
